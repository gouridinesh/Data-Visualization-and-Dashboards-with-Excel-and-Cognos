# Data-Visualization-and-Dashboards-with-Excel-and-Cognos
Projects and hands-on assignments completed using Excel and IBM Cognos, covering data visualization, charts, pivot tables, and dashboard creation.

Assignment Scenario

As a regional manager for a chain of car dealerships you need to create some visualizations to allow you to understand your car sales and profits for each dealer.

The dataset used in this comes from the following source: 
https://community.ibm.com/accelerators/?context=analytics&type=Data&product=Cognos%20Analytics&industry=Automotive
